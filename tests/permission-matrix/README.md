# 権限マトリクステスト（Permission Matrix Tests）

**作成日**: 2026-05-21  
**目的**: ACL エッジケースを含む権限制御の正しさを検証するテストスイート

---

## 概要

本テストスイートは、SID ベース権限フィルタリングの正しさを体系的に検証します。
Allow / Deny の競合、グループネスティング、継承権限、権限変更直後の動作など、
エッジケースを網羅的にテストします。

---

## テストカテゴリ

| カテゴリ | テスト数 | 説明 |
|---------|---------|------|
| 基本権限フィルタリング | 6 | 基本的な SID マッチング |
| グループネスティング | 4 | ネストされたグループの SID 解決 |
| 継承権限 | 4 | フォルダ継承と明示権限の組み合わせ |
| Fail-Closed | 5 | エラー時の安全側フォールバック |
| 権限変更反映 | 4 | ACL 変更後の検索結果変化 |
| エッジケース | 5 | SID 解決不能、空メタデータ等 |

---

## 実行方法

```bash
cd tests/permission-matrix
python3 -m pytest test_permission_scenarios.py -v
```

## テストシナリオ詳細

### 1. 基本権限フィルタリング

| # | シナリオ | ユーザー SID | ドキュメント SID | 期待結果 |
|---|---------|------------|----------------|---------|
| 1.1 | Everyone アクセス | [S-1-1-0] | [S-1-1-0] | ALLOW |
| 1.2 | グループマッチ | [S-1-5-21-...-512] | [S-1-5-21-...-512] | ALLOW |
| 1.3 | 不一致 | [S-1-5-21-...-1001] | [S-1-5-21-...-512] | DENY |
| 1.4 | 複数 SID の部分マッチ | [S-1-1-0, S-1-5-21-...-1001] | [S-1-5-21-...-1001] | ALLOW |
| 1.5 | 複数ドキュメント SID | [S-1-5-21-...-512] | [S-1-5-21-...-512, S-1-5-21-...-1100] | ALLOW |
| 1.6 | 空ユーザー SID | [] | [S-1-1-0] | DENY |

### 2. グループネスティング

| # | シナリオ | 説明 | 期待結果 |
|---|---------|------|---------|
| 2.1 | 直接グループメンバー | ユーザーが直接所属するグループの SID | ALLOW |
| 2.2 | ネストグループメンバー | 親グループ経由で間接所属 | ALLOW（展開済み SID リストに含まれる場合） |
| 2.3 | ネスト深度 3 | A → B → C のネスト | ALLOW（AD が全展開する場合） |
| 2.4 | 循環グループ参照 | A → B → A | エラーなし（AD が解決済み） |

### 3. 継承権限

| # | シナリオ | 説明 | 期待結果 |
|---|---------|------|---------|
| 3.1 | 親フォルダの権限継承 | /confidential/ の ACL が子ファイルに継承 | 親の SID で ALLOW |
| 3.2 | 明示権限が継承を上書き | ファイルに明示 ACL 設定 | 明示 SID で判定 |
| 3.3 | 継承無効化 | ファイルで継承をブロック | ファイル固有の SID のみ |
| 3.4 | 移動後の継承変更 | /public/ → /confidential/ に移動 | 移動先の継承が適用（メタデータ再生成後） |

### 4. Fail-Closed

| # | シナリオ | 説明 | 期待結果 |
|---|---------|------|---------|
| 4.1 | DynamoDB 接続エラー | user-access テーブルにアクセス不可 | 全ドキュメント DENY |
| 4.2 | ユーザーレコードなし | DynamoDB にユーザーの SID データなし | 全ドキュメント DENY |
| 4.3 | メタデータなしドキュメント | `.metadata.json` が存在しない | 該当ドキュメント DENY |
| 4.4 | 空の allowed_group_sids | `allowed_group_sids: []` | 該当ドキュメント DENY |
| 4.5 | 不正な SID 形式 | `allowed_group_sids: ["invalid"]` | 該当ドキュメント DENY |

### 5. 権限変更反映

| # | シナリオ | 説明 | 期待結果 |
|---|---------|------|---------|
| 5.1 | グループ追加後 | ユーザーを新グループに追加 | 新グループの文書が表示（AD Sync 後） |
| 5.2 | グループ削除後 | ユーザーをグループから削除 | 旧グループの文書が非表示（キャッシュ TTL 後） |
| 5.3 | ドキュメント ACL 変更 | ファイルの ACL を変更 | KB 再同期後に反映 |
| 5.4 | 緊急権限剥奪 | DynamoDB から SID 削除 | 即時全拒否 |

### 6. エッジケース

| # | シナリオ | 説明 | 期待結果 |
|---|---------|------|---------|
| 6.1 | SID 解決不能 | AD に存在しない SID | DENY（マッチしない） |
| 6.2 | 超長 SID リスト | 100+ グループに所属 | 正常動作（パフォーマンス確認） |
| 6.3 | Unicode ファイル名 | 日本語ファイル名のドキュメント | 正常動作 |
| 6.4 | 同時リクエスト | 同一ユーザーの並行検索 | 一貫した結果 |
| 6.5 | キャッシュ競合 | キャッシュ更新中のリクエスト | Fail-Closed or 旧キャッシュ |
