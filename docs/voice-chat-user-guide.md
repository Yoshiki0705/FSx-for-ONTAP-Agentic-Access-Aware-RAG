# 音声チャット ユーザーガイド

## 概要

音声チャット機能を使用すると、マイクから音声で質問し、AIが音声とテキストの両方で回答します。既存のRAG検索パイプライン（権限フィルタリング含む）と統合されており、テキスト入力と同じ品質の検索結果を音声で得られます。

---

## 利用条件

- `enableVoiceChat=true` でデプロイされていること
- ブラウザがマイクアクセスをサポートしていること（Chrome, Firefox, Safari, Edge）
- HTTPS接続であること（マイクアクセスにはHTTPSが必須）

---

## 使い方

### Step 1: マイクボタンを見つける

チャット入力エリアの右側に 🎤 マイクボタンが表示されます。

> **表示されない場合**: `enableVoiceChat=false` でデプロイされているか、ブラウザがマイクをサポートしていません。

### Step 2: 音声入力を開始する

1. 🎤 マイクボタンをクリック
2. ブラウザがマイクアクセス許可を要求 → **「許可」をクリック**
3. マイクボタンが赤色パルスアニメーションに変わる（録音中）
4. 波形アニメーションが表示される

### Step 3: 質問を話す

マイクに向かって質問を話します。例：
- 「この文書の要約を教えてください」
- 「売上レポートの主要なポイントは何ですか？」
- 「セキュリティポリシーについて教えて」

### Step 4: 録音を停止する

以下のいずれかで録音が停止します：
- 🎤 マイクボタンを再度クリック
- 30秒間無音が続いた場合（自動停止）
- キーボードショートカット: `Ctrl+Shift+V` (Mac: `Cmd+Shift+V`)

### Step 5: 回答を受け取る

- **テキスト**: チャットエリアに回答がストリーミング表示されます
- **音声**: スピーカーから回答が音声で再生されます
- **Citation**: 検索元のFSxファイルパスとアクセスレベルバッジが表示されます

---

## 通信モード

### REST モード（デフォルト）

- `voiceChatMode=rest` で動作
- Lambda経由でNova Sonic APIと通信
- 中程度のレイテンシ（バッファリング + バッチ処理）

### WebRTC モード（Phase 2）

- `voiceChatMode=webrtc` で動作
- AgentCore Runtime経由でリアルタイム双方向ストリーミング
- 低レイテンシ（peer-to-peer UDP通信）
- WebRTC接続失敗時は自動的にRESTモードにフォールバック

#### WebRTCモードの接続状態表示

| 表示 | 意味 |
|------|------|
| 「リアルタイム接続を確立中...」 | WebRTC接続確立中 |
| 「リアルタイムモードで接続中」 | WebRTC接続成功 |
| 「標準モードで継続します」 | RESTモードにフォールバック |
| 「接続品質が低下しています」 | パケットロス5%超 or RTT 500ms超 |

---

## 音声再生コントロール

回答の音声再生中に以下のコントロールが表示されます：

- ⏸️ **一時停止**: 音声再生を一時停止（テキスト表示は継続）
- ▶️ **再開**: 音声再生を再開
- 🔊 **音量調整**: スライダーで音量を調整
- ⏹️ **停止**: 音声再生を完全停止

> **重要**: 音声再生を停止してもテキスト表示は継続します。

---

## KB モード / Agent モード

音声チャットは両方のモードで動作します：

| モード | 動作 |
|--------|------|
| KB モード | 音声質問 → テキスト変換 → Bedrock KB検索 → 回答（テキスト+音声） |
| シングルAgent | 音声質問 → テキスト変換 → 選択中のAgent実行 → 回答（テキスト+音声） |
| マルチAgent | 音声質問 → テキスト変換 → Supervisor Agent → 回答（テキスト+音声） |

---

## 権限フィルタリング

音声チャットでも**テキスト入力と同一の権限フィルタリング**が適用されます：

- 管理者のみアクセス可能な文書は管理者にのみ回答
- 一般ユーザーには公開文書のみで回答
- SID/UID/GIDベースのフィルタリングが音声検索結果にも適用

---

## エラーと対処法

| エラー | 原因 | 対処法 |
|--------|------|--------|
| マイクボタンが表示されない | `enableVoiceChat=false` | CDKパラメータを確認 |
| 「マイクへのアクセスが拒否されました」 | ブラウザ設定でマイクがブロック | ブラウザ設定 → サイト設定 → マイクを「許可」に変更 |
| 「音声サービスに接続できません」 | WebSocket/WebRTC接続失敗 | ネットワーク接続を確認。テキスト入力で継続可能 |
| 「音声を認識できませんでした」 | 音声が不明瞭 or 無音 | もう一度はっきりと話す |
| 「リアルタイムモードに接続できません」 | WebRTC接続タイムアウト | 自動的にRESTモードで継続。「再接続」ボタンで再試行可能 |

## 対応言語

音声チャットは以下の8言語に対応しています：

- 🇯🇵 日本語
- 🇺🇸 English
- 🇰🇷 한국어
- 🇨🇳 简体中文
- 🇹🇼 繁體中文
- 🇫🇷 Français
- 🇩🇪 Deutsch
- 🇪🇸 Español

UI テキスト（ボタンラベル、エラーメッセージ等）はユーザーの選択言語で表示されます。音声認識・音声合成もNova Sonicの多言語対応により、選択言語に応じて動作します。

## 技術仕様

| 項目 | 値 |
|------|-----|
| 音声入力サンプルレート | 16kHz |
| 音声出力サンプルレート | 24kHz |
| チャンネル数 | 1（モノラル） |
| チャンク間隔 | 100ms |
| 無音タイムアウト | 30秒 |
| 自動再接続 | 最大3回 |
| WebRTC接続タイムアウト | 15秒 |
| フォールバック閾値 | 3回連続失敗 |
