# AI利用ポリシー 組織テンプレート

**作成日**: 2026-05-24  
**対象**: 組織ごとのAI利用ルールを定義するためのテンプレート

---

## 目的

本テンプレートは、Permission-aware RAG システムを組織内で利用する際の行動規範を定義します。「AIの回答をどこまで信頼してよいか」「どの場面で人間の判断が必要か」を明確にし、安全かつ効果的なAI活用を促進します。

---

## 1. AI出力の位置づけ

| 区分 | 定義 | AI回答の扱い |
|------|------|-------------|
| **参考情報** | 意思決定の補助材料 | そのまま参考にしてよい |
| **要確認情報** | 正確性の検証が必要 | 原典を確認してから使用 |
| **使用禁止** | AIの回答を使ってはいけない場面 | 人間の専門家が判断 |

---

## 2. 場面別ルール

### ✅ AI回答をそのまま参考にしてよい場面

- [ ] 社内文書の所在確認（「〇〇に関する資料はどこにありますか？」）
- [ ] 過去の議事録・報告書の要約
- [ ] 社内規程の一般的な確認（「出張精算のルールは？」）
- [ ] 製品仕様の概要確認
- [ ] FAQ的な質問への回答

### ⚠️ AI回答を使う前に原典確認が必要な場面

- [ ] 契約書の条項解釈
- [ ] 規制要件への適合性判断
- [ ] 数値データ（売上、予算、KPI）の引用
- [ ] 顧客向け資料への転記
- [ ] 技術仕様の正確な値（寸法、公差、材質）

### ❌ AI回答を最終判断に使ってはいけない場面

- [ ] 法的判断（契約締結、訴訟対応、コンプライアンス判定）
- [ ] 医療判断（診断、処方、治療方針）
- [ ] 人事判断（採用、評価、懲戒）
- [ ] 財務判断（投資決定、与信判断）
- [ ] 安全に関わる判断（製品安全、労働安全）
- [ ] 個人情報の取り扱い判断

## 4. インシデント対応

### AI回答に問題があった場合

1. **発見者**: 問題のある回答を記録（スクリーンショット + 質問文）
2. **報告**: AI利用ポリシー責任者に報告（24時間以内）
3. **影響評価**: 問題のある回答が業務判断に使われたか確認
4. **是正**: 必要に応じて業務判断の見直し
5. **再発防止**: Guardrailsポリシーの調整、ドキュメントの修正

### エスカレーション基準

| レベル | 条件 | 対応 |
|--------|------|------|
| Low | 回答が不正確だが業務影響なし | 記録のみ |
| Medium | 回答が不正確で業務判断に影響の可能性 | 責任者に報告 + 判断の見直し |
| High | 権限外情報の表示、PII漏えい | 即時報告 + システム停止検討 |

---

## 5. 定期レビュー

| 項目 | 頻度 | 担当 |
|------|------|------|
| AI利用ログレビュー | 月次 | 監査責任者 |
| ポリシー見直し | 四半期 | AI利用ポリシー責任者 |
| ユーザー教育 | 半期 | 人事部 + IT部 |
| Guardrails設定レビュー | 四半期 | IT部 |

---

## 6. ユーザー同意事項

本システムを利用する全ユーザーは、以下に同意したものとみなします:

- [ ] AI回答は参考情報であり、最終判断は自身の責任で行います
- [ ] 「使用禁止」場面ではAI回答を判断根拠にしません
- [ ] 問題のある回答を発見した場合は速やかに報告します
- [ ] 個人情報を含む質問を行う際はGuardrailsが有効であることを確認します
- [ ] AI回答を社外に共有する際は原典を確認します

---

## カスタマイズガイド

本テンプレートは組織の特性に合わせてカスタマイズしてください:

- **製造業**: 「技術仕様の正確な値」を「使用禁止」に格上げ検討
- **金融**: 「数値データの引用」を「使用禁止」に格上げ検討
- **医療**: 「医療判断」セクションを詳細化（診療科別ルール）
- **公共**: 「住民対応」「議会答弁」の場面別ルールを追加
- **法務**: 「法的判断」セクションを詳細化（案件種別ルール）
