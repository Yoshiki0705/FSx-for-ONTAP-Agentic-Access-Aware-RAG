# 数据就绪度评估模板

**🌐 Language:** [日本語](../data-readiness-assessment.md) | [English](../en/data-readiness-assessment.md) | [한국어](../ko/data-readiness-assessment.md) | **简体中文** | [繁體中文](../zh-TW/data-readiness-assessment.md) | [Français](../fr/data-readiness-assessment.md) | [Deutsch](../de/data-readiness-assessment.md) | [Español](../es/data-readiness-assessment.md)

**创建日期**: 2026-05-24  
**对象**: 用于在 PoC 启动前评估数据准备状况的模板

---

## 概述

本模板帮助评估将要导入 Permission-aware RAG 系统的数据准备状况，支持安全且有效的 PoC 实施。请由数据所有者与技术负责人共同填写。

---

| # | 确认项 | 回答 |
|---|---------|------|
| 1.1 | 数据的物理存储位置是？ | ☐ 本地文件服务器 ☐ AWS上（S3/EFS/FSx） ☐ SaaS ☐ 其他: ________ |
| 1.2 | 数据量（文件数 / 总容量） | 文件数: ________ 个，总容量: ________ GB |
| 1.3 | 文件格式构成 | PDF: ___% / DOCX: ___% / TXT: ___% / 其他: ___% |
| 1.4 | 数据更新频率 | ☐ 每日 ☐ 每周 ☐ 每月 ☐ 不定期 ☐ 静态（无更新） |
| 1.5 | 数据语言 | ☐ 日语 ☐ 英语 ☐ 混合 ☐ 其他: ________ |

## 2. 数据分类

| 机密级别 | 定义 | 对应文件数 | 示例 |
|-----------|------|-------------|-----|
| **公开** | 可对外公开 | ________ 个 | 产品目录、新闻稿 |
| **内部限定** | 全体员工可访问 | ________ 个 | 内部规程、福利信息 |
| **部门限定** | 仅特定部门 | ________ 个 | 项目计划、技术规格 |
| **机密** | 仅特定职位 | ________ 个 | 财务报告、人事信息 |
| **绝密** | 仅指定人员 | ________ 个 | M&A 资料、法律诉讼文档 |

## 3. 权限结构确认

| # | 确认项 | 回答 |
|---|---------|------|
| 3.1 | 当前的权限管理方式是？ | ☐ NTFS ACL (Active Directory) ☐ UNIX 权限 ☐ 应用程序专有 ☐ 无（所有人可访问） |
| 3.2 | 权限组数量 | ________ 个组 |
| 3.3 | 权限的层级结构 | ☐ 扁平 ☐ 2层 ☐ 3层以上 ☐ 不明 |
| 3.4 | 权限变更频率 | ☐ 每日 ☐ 每周 ☐ 每月 ☐ 每季度 ☐ 几乎没有 |
| 3.5 | 是否对权限的准确性有信心 | ☐ 高 ☐ 中等 ☐ 低（需要盘点） |

---

## 4. 数据质量确认

| # | 确认项 | 回答 | 影响 |
|---|---------|------|------|
| 4.1 | 是否有需要 OCR 的扫描 PDF | ☐ 无 ☐ 部分 ☐ 大部分 | 影响 RAG 精度 |
| 4.2 | 文件名是否反映内容 | ☐ 是 ☐ 部分 ☐ 否 | 影响检索精度 |
| 4.3 | 文件夹结构是否经过逻辑整理 | ☐ 是 ☐ 部分 ☐ 否 | 影响权限设计 |
| 4.4 | 是否存在重复文件 | ☐ 无 ☐ 少量 ☐ 大量 | 影响存储成本 |
| 4.5 | 是否混入了过时/无效的文件 | ☐ 无 ☐ 少量 ☐ 大量 | 影响回答精度 |

---

## 5. 合规·隐私确认

| # | 确认项 | 回答 | 应对 |
|---|---------|------|------|
| 5.1 | 是否包含个人信息（PII） | ☐ 无 ☐ 有 → 种类: ________ | 脱敏 or Guardrails PII 检测 |
| 5.2 | 是否为受监管数据 | ☐ 无 ☐ 有 → 监管: ________ | 必须进行法务确认 |
| 5.3 | 是否存在数据出境限制 | ☐ 无 ☐ 有 | 影响区域选择 |
| 5.4 | 是否有数据保留期限要求 | ☐ 无 ☐ 有 → 期限: ________ | 影响备份设计 |
| 5.5 | 是否有审计轨迹保全要求 | ☐ 无 ☐ 有 | 必须 `enableMonitoring=true` |

## 7. 就绪度判定

根据所有章节的回答，进行以下判定：

| 判定 | 条件 |
|------|------|
| **Ready** | 第 1-6 章节全部回答完毕，已完成 PII 应对，已获得数据所有者批准 |
| **Conditional** | 部分未回答，但可使用演示数据启动 → 并行准备数据 |
| **Not Ready** | 数据所在不明、权限结构不明、PII 未确认 → 需先进行数据整备阶段 |
