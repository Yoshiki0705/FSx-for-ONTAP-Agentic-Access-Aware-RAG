**🌐 Language:** [日本語](../data-readiness-assessment.md) | [English](../en/data-readiness-assessment.md) | **한국어** | [简体中文](../zh-CN/data-readiness-assessment.md) | [繁體中文](../zh-TW/data-readiness-assessment.md) | [Français](../fr/data-readiness-assessment.md) | [Deutsch](../de/data-readiness-assessment.md) | [Español](../es/data-readiness-assessment.md)

**대상**: PoC 시작 전에 데이터의 준비 상태를 평가하기 위한 템플릿

---

## 개요

본 템플릿은 Permission-aware RAG 시스템에 투입할 데이터의 준비 상태를 평가하여, 안전하고 효과적인 PoC 실시를 지원합니다. 데이터 오너와 기술 리드가 공동으로 작성해 주세요.

---

## 1. 데이터 소재 확인

| # | 확인 항목 | 답변 |
|---|---------|------|
| 1.1 | 데이터의 물리적 저장 위치는? | ☐ 온프레미스 파일 서버 ☐ AWS상(S3/EFS/FSx) ☐ SaaS ☐ 기타: ________ |
| 1.2 | 데이터 양(파일 수 / 총 용량) | 파일 수: ________ 건, 총 용량: ________ GB |
| 1.3 | 파일 형식 내역 | PDF: ___% / DOCX: ___% / TXT: ___% / 기타: ___% |
| 1.4 | 데이터 갱신 빈도 | ☐ 일별 ☐ 주별 ☐ 월별 ☐ 비정기 ☐ 정적(갱신 없음) |
| 1.5 | 데이터 언어 | ☐ 일본어 ☐ 영어 ☐ 혼재 ☐ 기타: ________ |

## 4. 데이터 품질 확인

| # | 확인 항목 | 답변 | 영향 |
|---|---------|------|------|
| 4.1 | OCR이 필요한 스캔 PDF가 있는가 | ☐ 없음 ☐ 일부 ☐ 대부분 | RAG 정확도에 영향 |
| 4.2 | 파일명이 내용을 반영하는가 | ☐ 예 ☐ 일부 ☐ 아니오 | 검색 정확도에 영향 |
| 4.3 | 폴더 구조가 논리적으로 정리되어 있는가 | ☐ 예 ☐ 일부 ☐ 아니오 | 권한 설계에 영향 |
| 4.4 | 중복 파일이 있는가 | ☐ 없음 ☐ 소수 ☐ 다수 | 스토리지 비용에 영향 |
| 4.5 | 오래되거나 무효한 파일이 혼재되어 있는가 | ☐ 없음 ☐ 소수 ☐ 다수 | 답변 정확도에 영향 |

## 7. 준비도 판정

모든 섹션의 답변을 바탕으로 다음 판정을 실시합니다:

| 판정 | 조건 |
|------|------|
| **Ready** | 섹션 1-6 모두 답변 완료, PII 대응 완료, 데이터 오너 승인 완료 |
| **Conditional** | 일부 미답변이 있으나 데모 데이터로 시작 가능 → 병행하여 데이터 준비 |
| **Not Ready** | 데이터 소재 불명, 권한 구조 불명, PII 미확인 → 데이터 정비 단계가 우선 |
