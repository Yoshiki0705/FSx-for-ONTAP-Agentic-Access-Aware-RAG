# ROI ダッシュボード解釈ガイド

**作成日**: 2026-05-24  
**対象**: ビジネススポンサー、プロジェクトマネージャー、評価担当者

---

## ダッシュボードの見方

ROI ダッシュボード（`{prefix}-roi-metrics`）は3行6ウィジェットで構成されています。

---

## Row 1: 利用状況

### Daily Query Count（日次クエリ数）

| 状態 | 意味 | アクション |
|------|------|-----------|
| 増加傾向 | ユーザー採用が進んでいる | 成功。次フェーズの検討開始 |
| 横ばい | 安定利用 | 特になし |
| 減少傾向 | ユーザー離脱の可能性 | ユーザーヒアリング実施。回答品質の確認 |
| ゼロ | システム未使用 or 障害 | アラーム確認。ユーザーへの周知確認 |

**ベースライン設定**: PoC開始時の1週目の平均値を「初期ベースライン」として記録してください。

### Smart Routing Distribution（ルーティング分布）

| 状態 | 意味 | アクション |
|------|------|-----------|
| Simple 80%+ | 正常（大半が簡単な質問） | コスト効率が良い状態 |
| Full-context 20%+ | 複雑なクエリが増加 | コスト増加の可能性。ユースケース確認 |
| Full-context 急増 | 異常（攻撃 or 誤設定） | コスト異常アラート確認。Guardrails確認 |

### User Feedback（ユーザーフィードバック）

| 状態 | 意味 | アクション |
|------|------|-----------|
| 👍 80%+ | 回答品質が高い | 成功指標達成 |
| 👎 30%+ | 回答品質に問題 | negative フィードバックのクエリパターンを分析 |
| フィードバックなし | ボタンが使われていない | UI の視認性改善。ユーザーへの案内 |

---

## Row 2: パフォーマンス & セキュリティ

### Response Time P50/P95/P99

| 指標 | 目標値（PoC） | 超過時のアクション |
|------|-------------|-----------------|
| P50 | < 3秒 | 正常範囲 |
| P95 | < 10秒 | モデル選択の確認。コンテキストサイズの確認 |
| P99 | < 30秒 | Cold Start の影響確認。Provisioned Concurrency 検討 |

### Permission Filtering（権限拒否数）

| 状態 | 意味 | アクション |
|------|------|-----------|
| 安定（低い値） | 正常。権限設計が適切 | 特になし |
| 急増 | 権限変更があった or 不正アクセス試行 | CloudTrail確認。権限設計レビュー |
| ゼロ | 全員が全文書にアクセス可能（権限設計の問題） | 権限設計の見直し |

### Cache Invalidations

| 状態 | 意味 | アクション |
|------|------|-----------|
| 低頻度 | 権限変更が少ない（安定運用） | 特になし |
| 高頻度 | 権限変更が頻繁 | 権限設計の安定化を検討 |

---

## Row 3: 運用

### KB Auto-Sync Activity

| 状態 | 意味 | アクション |
|------|------|-----------|
| Changed Files > 0 | 新しいドキュメントが追加されている | 正常 |
| Ingestion Jobs 増加 | KB が最新状態に保たれている | 正常 |
| Changed Files = 0（長期間） | ドキュメント追加が停止 | データ投入フローの確認 |

### Guardrail Decisions

| 状態 | 意味 | アクション |
|------|------|-----------|
| Allowed >> Blocked | 正常利用 | 特になし |
| Blocked 急増 | 不適切なクエリ増加 or Guardrails 設定が厳しすぎる | Guardrails 設定レビュー |

## ROI 計算方法

```
月間ROI = (削減時間 × 時間単価) - システムコスト

削減時間 = (手動検索時間 - AI検索時間) × 月間クエリ数
         = (Before値 - P50応答時間) × Daily Query Count × 営業日数

例:
  Before: 15分/件（手動検索）
  After: P50 = 3秒 ≈ 0.05分
  月間クエリ: 500件
  時間単価: ¥5,000/時間

  削減時間 = (15 - 0.05) × 500 = 7,475分 = 124.6時間
  削減コスト = 124.6 × ¥5,000 = ¥623,000/月
  システムコスト = $430 × 150 = ¥64,500/月
  月間ROI = ¥623,000 - ¥64,500 = ¥558,500/月
```

**Before値の設定方法**: PoC開始前にユーザーアンケートで「現在の平均検索時間」を計測し、CloudWatch Dashboard の Annotation（水平線）として設定してください。
