## 発見された問題と対応

### FSx ONTAP S3サービス応答なし

**症状**: S3 AP経由の `ListObjectsV2` が `ConnectionClosedError` を返す  
**影響**: SFTP put、KB Auto-Sync スキャン、Ingestion Trigger がブロック  
**原因推定**: FSx ONTAP の S3 プロトコルサービスが無効化されている、またはSVMのS3設定が不完全  
**対応**: ONTAP REST API (`/api/protocols/s3/services`) で S3 サービスを有効化する必要あり  
**アクセス手段**: FSx ONTAP 管理IP (10.0.3.72) への到達にはVPC内のジャンプホストが必要だが、現在全インスタンスが ConnectionLost 状態

### 実施した対応

1. ✅ Lambda関数をFSx ONTAP VPC内に配置（subnet-0307ebbd55b35c842, subnet-0af86ebd3c65481b8）
2. ✅ Lambda用セキュリティグループ作成（sg-016c5160e98c4dd33、全アウトバウンド許可）
3. ✅ FSx SGにLambda SGからのHTTPS(443)インバウンド追加
4. ✅ Lambda実行ロールにVPCアクセス権限追加
