# PoC ワークショップ スライドテンプレート

**対象**: パートナーが顧客向けに実施する90分ワークショップ用スライド構成

---

## スライド構成（推奨: 20枚）

### Part 1: 課題と解決策（10分 / 5枚）

| # | タイトル | 内容 | 話者ノート |
|---|---------|------|-----------|
| 1 | 表紙 | 「権限を守るAI文書検索 — 90分体験ワークショップ」 | 参加者の業種・役割を確認 |
| 2 | 今日の課題 | 「必要な文書に辿り着けない」「権限管理と検索が分離」「パートナー連携が手動」 | 参加者に「あるある」を聞く |
| 3 | Before / After | 導入前の課題 → 導入後の変化（README の Before/After 表を使用） | 定量効果を強調 |
| 4 | アーキテクチャ概要 | README の Architecture 図 | 「既存のファイルサーバーをそのまま活用」を強調 |
| 5 | 本日のゴール | 「90分後に: ①権限差異を体験 ②自社データでの効果をイメージ ③次のステップを決定」 | — |

### Part 2: ハンズオン（60分 / 8枚）

| # | タイトル | 内容 | 話者ノート |
|---|---------|------|-----------|
| 6 | デモ環境アクセス | CloudFront URL、テストユーザー情報 | 全員がサインインできることを確認 |
| 7 | シナリオ1: 管理者検索 | admin でサインイン → 「売上は？」→ 機密文書が表示される | Citation のファイルパスに注目させる |
| 8 | シナリオ2: 一般ユーザー検索 | user でサインイン → 同じ質問 → 公開文書のみ表示 | 「同じ質問でも結果が違う」を体感 |
| 9 | シナリオ3: Agent モード | Agent モードに切替 → 多段階推論のデモ | 「検索だけでなく分析もできる」 |
| 10 | シナリオ4: Smart Routing | ON/OFF で応答速度・コストの違いを確認 | 「90%のクエリは低コストモデルで十分」 |
| 11 | シナリオ5: 業種別データ | 参加者の業種に合わせたデモデータで検索 | 業種別デモデータパックを使用 |
| 12 | ディスカッション | 「自社のどのデータで試したいか？」「誰がアクセスすべきか？」 | ホワイトボードに書き出す |
| 13 | Q&A | 技術的な質問への回答 | partner-faq.md を参照 |

## ファシリテーションガイド

### 事前準備（ワークショップ前日まで）

- [ ] デモ環境のデプロイ確認（CloudFront URL にアクセスできること）
- [ ] テストユーザーでのサインイン確認
- [ ] 参加者の業種に合わせたデモデータパックの選択
- [ ] プロジェクター / 画面共有の確認
- [ ] 参加者リスト（役割: ビジネス / 技術 / セキュリティ）

### 当日の進行ポイント

| 時間 | ポイント |
|------|---------|
| 開始5分 | 参加者の期待値を確認（「今日何を持ち帰りたいか」） |
| 10分 | 課題共感を得る（「この問題ありますか？」と挙手を求める） |
| 30分 | 全員がハンズオンに参加していることを確認（つまずいている人をサポート） |
| 60分 | ディスカッションで「自社データ」の話を引き出す |
| 80分 | 次のステップを具体的に合意（日程、担当者、成果物） |

### よくある質問への回答準備

→ [パートナー FAQ](partner-faq.md) を事前に確認

### ワークショップ後のフォローアップ

1. **当日中**: 参加者にお礼メール + 資料共有
2. **翌営業日**: データレディネス評価テンプレートを送付
3. **1週間後**: PoC 成功基準の合意ミーティング設定
4. **2週間後**: PoC 開始
