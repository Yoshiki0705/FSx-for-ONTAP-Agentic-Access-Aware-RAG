# 多言語ドキュメントのティア方針

**🌐 Language:** **日本語** | [English](en/i18n-policy.md)

---

## 結論

このリポジトリの doc は 8 言語にありますが、**すべての言語が同じ内容を持っているわけではありません。** 翻訳が原文の一部だけを訳している場合、その doc は開示バナーを持ちます。`scripts/check-i18n.py` が、バナーの無い抄訳と、抄訳でなくなったのに残っているバナーの両方を検出します。

**隠さないことが目的です。** 「翻訳がある」と「同じ内容が読める」は違います。前者だけを示すと、読者は原文にしか書かれていない制約を知らずに設計します。

---

## 3 つのティア

| ティア | 言語 | 求めるもの |
|--------|------|----------|
| 1（原文） | 日本語 | すべての doc の原本。ここに無い内容は他の言語にも無い |
| 2（対訳） | English | ティア 1 と**構成の一致**（節の数と並び）。差があるなら抄訳バナーを付ける |
| 3（部分訳） | ko / zh-CN / zh-TW / fr / de / es | 主要 doc の部分訳。差があるなら抄訳バナーを付ける。**未翻訳は欠落ではなく範囲外** |

`docs/<lang>/` がその doc の言語を決めます。**日本語は例外で `docs/` 直下**にあります（`docs/ja/` は存在しません）。

---

## 抄訳バナー

翻訳が原文の一部しか訳していない場合、言語スイッチャの直後に次の 2 行を置きます。

```markdown
<!-- i18n:abridged -->
> **⚠️ 抄訳**: この翻訳は日本語版の一部です。完全な内容は [日本語版](../operations-runbook.md) を参照してください。
```

`<!-- i18n:abridged -->` が機械可読なマーカーで、その下の文が読者向けの表示です。**マーカーだけ・文だけの片方は不可です。** 前者は読者に見えず、後者は検査に見えません。

### 検査の内容

`python3 scripts/check-i18n.py`（`--selftest` を先に実行）が次を見ます。

| 検査 | 落ちる条件 |
|------|----------|
| 未開示の抄訳 | 原文と翻訳の**節の数**が違うのに、マーカーが無い |
| 陳腐化したバナー | 節の数が一致しているのに、マーカーが残っている |
| マーカーと表示の不一致 | マーカーがあるのに読者向けの文が無い（またはその逆） |

**節の数で判定するのは、数えられるからです。** 文の意味の一致は機械では見られないので、翻訳が「章を落としているか」だけを見ます。**章の中身が薄くなっている場合は検出できません。** これは検査の限界で、範囲は実行時に出力します。

### 未翻訳の原文の検出

節の数を見る検査は、**見出しごと原文（日本語）のまま置かれた doc を通します**（節の数は一致するため）。実際に 2 ファイルがその状態で通過していました。

`python3 scripts/check-untranslated.py`（`--selftest` を先に実行）が、**7 言語すべて**に残った原文を検出します。ko / zh は漢字が正当に現れるため日本語固有のかなだけを、Latin 系（en / fr / de / es）は漢字とかなの両方を見ます。

**当初はティア 2 の英語版だけを対象にしていました。** その後 2026-09 にティア 3 の未翻訳（6 言語 × 6 ファイル、約 1587 行）を解消したため、範囲を広げています。範囲を戻すと、同じ状態——見出しだけ訳された原文のコピー——が再び入っても検出できません。

意図的に原文を残す箇所（i18n キーの対応表、利用者に見せる言語名、分類器が literal に照合する日本語キーワード、日本語の入力例）は領域で囲みます。

```markdown
<!-- allow:source-language:start --> <!-- なぜ残すかを書く -->
| `signin.adSignIn` | ADでサインイン | Sign in with AD |
<!-- allow:source-language:end -->
```

行ごとではなく領域にしたのは、表の行に HTML コメントを置くと読者に見えるためです。**閉じ忘れた領域は違反として検出します。** 閉じないと以降のすべてが除外され、検出器が沈黙します。

`--report` で言語ごとの網羅状況を出力します。**この表は doc に固定値として書きません。** 書けば更新が人手に依存し、古くなったことに誰も気づけません。

---

## 未翻訳の扱い

**未翻訳は欠落ではなくティア 3 の範囲です。** プレースホルダのページを作らないでください。空のページは、内容があると読者に思わせてから期待を裏切ります。

翻訳が無い場合、リンクは原文（日本語）か英語版を指します。言語スイッチャに存在しないファイルを並べると、リンク切れとして `scripts/check-doc-links.py` が落とします。

---

## 更新時の順序

1. 日本語版を直す
2. English を同じ変更で直す（ティア 2 は構成の一致を求めるため）
3. ティア 3 の言語は、その doc に既にその言語があるなら直す。無ければ作らない
4. 直しきれない言語には抄訳バナーを付ける

**「あとで直す」を選ぶ場合、バナーを付けてから次に進んでください。** バナーの無い抄訳は、読者にとって完全な翻訳と区別できません。
