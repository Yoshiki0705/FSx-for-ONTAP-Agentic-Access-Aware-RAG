# データレディネス評価テンプレート

**🌐 Language:** **日本語** | [English](en/data-readiness-assessment.md)

**作成日**: 2026-05-24  
**対象**: PoC 開始前にデータの準備状況を評価するためのテンプレート

---

## 概要

本テンプレートは、Permission-aware RAG システムに投入するデータの準備状況を評価し、安全かつ効果的な PoC 実施を支援します。データオーナーと技術リードが共同で記入してください。

---

## 1. データ所在の確認

| # | 確認項目 | 回答 |
|---|---------|------|
| 1.1 | データの物理的な保存場所は？ | ☐ オンプレミスファイルサーバー ☐ AWS上（S3/EFS/FSx） ☐ SaaS ☐ その他: ________ |
| 1.2 | データ量（ファイル数 / 総容量） | ファイル数: ________ 件、総容量: ________ GB |
| 1.3 | ファイル形式の内訳 | PDF: ___% / DOCX: ___% / TXT: ___% / その他: ___% |
| 1.4 | データの更新頻度 | ☐ 日次 ☐ 週次 ☐ 月次 ☐ 不定期 ☐ 静的（更新なし） |
| 1.5 | データの言語 | ☐ 日本語 ☐ 英語 ☐ 混在 ☐ その他: ________ |

## 4. データ品質の確認

| # | 確認項目 | 回答 | 影響 |
|---|---------|------|------|
| 4.1 | OCR が必要なスキャン PDF はあるか | ☐ なし ☐ 一部 ☐ 大半 | RAG 精度に影響 |
| 4.2 | ファイル名が内容を反映しているか | ☐ はい ☐ 一部 ☐ いいえ | 検索精度に影響 |
| 4.3 | フォルダ構造が論理的に整理されているか | ☐ はい ☐ 一部 ☐ いいえ | 権限設計に影響 |
| 4.4 | 重複ファイルはあるか | ☐ なし ☐ 少数 ☐ 多数 | ストレージコストに影響 |
| 4.5 | 古い/無効なファイルが混在しているか | ☐ なし ☐ 少数 ☐ 多数 | 回答精度に影響 |

## 7. レディネス判定

全セクションの回答に基づき、以下の判定を行います:

| 判定 | 条件 |
|------|------|
| **Ready** | セクション1-6全て回答済み、PII対応済み、データオーナー承認済み |
| **Conditional** | 一部未回答あるが、デモデータで開始可能 → 並行してデータ準備 |
| **Not Ready** | データ所在不明、権限構造不明、PII未確認 → データ整備フェーズが先 |
