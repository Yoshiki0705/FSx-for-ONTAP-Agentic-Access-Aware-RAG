# コア網 通信障害対応ランブック（ネットワーク運用部）

## 目的
音声およびデータ通信に影響する障害が発生したときの、初動から復旧報告までの手順を定める。対象はネットワーク運用部の当番担当者である。

## 重大度の区分
| 区分 | 影響範囲 | 初動の期限 | 経営層への報告 |
|---|---|---|---|
| S1 | 10万契約以上に影響 | 検知から5分以内 | 15分以内 |
| S2 | 1万契約以上10万契約未満 | 検知から15分以内 | 60分以内 |
| S3 | 1万契約未満 | 検知から30分以内 | 翌営業日 |

## 初動手順
1. 監視ダッシュボードで、アラートの発生元と影響エリアを特定する。
2. 障害対策本部の招集を判断する（S1とS2は必須）。
3. 予備系への切り替えが可能か確認し、切り替え前に当番責任者の承認を得る。
4. 公式サイトへの第一報を、発生から30分以内に広報部へ依頼する。

## 復旧後の対応
- [ ] 復旧時刻と影響契約数を記録する
- [ ] 5営業日以内に原因分析の報告書を作成する
- [ ] 再発防止策の期限を2026年内に設定する

## 過去事例
2026年2月の交換機の設定誤りでは、S2相当の障害が47分続いた。影響は約3万2千契約であった。

## 連絡体制
- 当番責任者は、検知から10分以内に障害対策本部の連絡網へ一斉通知を行う
- 外部の回線事業者への問い合わせは、S1とS2で必ず実施する
- 広報部への連絡は、影響エリアと推定復旧時刻を含めて行う

## 記録すべき項目
| 項目 | 内容 |
|---|---|
| 検知時刻 | アラートの発生時刻 |
| 影響範囲 | エリアと契約数 |
| 実施した対応 | 切り替え、再起動、設定変更 |
