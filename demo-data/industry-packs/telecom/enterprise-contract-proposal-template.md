# 法人向け回線サービス 提案書テンプレート（法人営業部）

## 使い方
本テンプレートは、法人営業部が顧客に提示する提案書の雛形である。【】内を案件ごとに書き換える。

## 1. 提案の概要
【顧客名】向けに、拠点間を結ぶ専用回線と、モバイル回線【台数】回線を提案する。契約期間は【36】か月とする。

## 2. 料金の目安
| 項目 | 単価（月額・税抜） | 備考 |
|---|---|---|
| 専用回線 1Gbps | 148,000円 | 拠点ごと |
| 専用回線 10Gbps | 520,000円 | 拠点ごと |
| 法人モバイル回線 | 2,400円 | 100回線以上で10%割引 |
| 運用監視オプション | 30,000円 | 24時間365日 |

## 3. 値引きの承認ルール
- 10%以下の値引きは、営業課長の承認で可
- 10%超から20%以下は、営業部長の承認が必要
- 20%超は、役員会議の承認が必要

## 4. 過去の提案例
2026年3月の製造業向け案件では、5拠点で専用回線を提案し、月額合計は約1,100万円、割引率は12%であった。

## 5. 確認事項
- [ ] 顧客の希望する開通日を確認した
- [ ] 回線の品質保証の内容を顧客に説明した

## 6. 提案後の流れ
| 段階 | 期限の目安 | 担当 |
|---|---|---|
| 見積書の提出 | 提案から5営業日以内 | 営業担当 |
| 技術確認 | 見積書の提出から10営業日以内 | 技術担当 |
| 契約書の締結 | 合意から14日以内 | 法務担当 |

提案書には、顧客の機密情報を含めない。共有の際は、顧客ごとの閲覧権限を確認する。
