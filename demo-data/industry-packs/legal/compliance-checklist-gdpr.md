# GDPR対応チェックリスト

## 概要

本チェックリストは、EU一般データ保護規則（GDPR）への準拠状況を確認するためのものである。EU域内の個人データを取り扱う全ての事業部門は、本チェックリストに基づき年次で自己点検を実施すること。

## 1. データマッピング・記録

- [ ] 個人データの処理活動記録（ROPA）を作成・更新しているか
- [ ] 処理する個人データの種類、目的、保存期間を明確にしているか
- [ ] データフローマップ（EU域外への移転を含む）を作成しているか
- [ ] 処理の法的根拠（同意、契約、正当利益等）を特定しているか

## 2. データ主体の権利保障

- [ ] アクセス権への対応手順が整備されているか（30日以内の回答）
- [ ] 訂正権・削除権（忘れられる権利）への対応が可能か
- [ ] データポータビリティ権への対応（機械可読形式での提供）が可能か
- [ ] 処理制限権・異議申立権への対応手順があるか
- [ ] 自動化された意思決定・プロファイリングに関する説明が可能か

## 3. 同意管理

- [ ] 同意は自由意思に基づき、明確かつ具体的に取得しているか
- [ ] 同意の撤回が容易に行える仕組みがあるか
- [ ] 16歳未満の子どもの個人データについて保護者の同意を取得しているか
- [ ] 同意取得の記録を保持しているか

## 4. セキュリティ対策

- [ ] 個人データの暗号化（保存時・転送時）を実施しているか
- [ ] アクセス制御（最小権限の原則）を適用しているか
- [ ] 定期的なセキュリティ評価・ペネトレーションテストを実施しているか
- [ ] データ侵害発生時の72時間以内の監督機関への通知体制があるか

## 5. データ保護影響評価（DPIA）

- [ ] 高リスク処理に対してDPIAを実施しているか
- [ ] DPIAの結果に基づくリスク軽減措置を講じているか
- [ ] DPO（データ保護責任者）のレビューを受けているか

## 6. 越境データ移転

- [ ] EU域外への移転に適切な保護措置（SCC、BCR等）を講じているか
- [ ] 移転先国の十分性認定の有無を確認しているか
- [ ] 移転影響評価（TIA）を実施しているか

## 7. 組織体制

- [ ] DPO（データ保護責任者）を選任しているか
- [ ] 従業員向けGDPR研修を年1回以上実施しているか
- [ ] 処理者（委託先）との間でデータ処理契約を締結しているか
- [ ] インシデント対応計画を策定・訓練しているか

## 対応期限

各部門は毎年3月末までに本チェックリストの自己点検を完了し、法務部に報告すること。
