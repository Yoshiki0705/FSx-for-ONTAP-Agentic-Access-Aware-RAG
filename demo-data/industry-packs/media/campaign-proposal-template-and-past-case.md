# キャンペーン企画提案書テンプレートと過去事例

## 1. 提案書テンプレート
| 章 | 記載内容 |
|---|---|
| 1. 課題と目的 | 広告主の課題、キャンペーンの目的、達成指標 |
| 2. 対象 | 想定する読者・視聴者層と、媒体との適合 |
| 3. 施策 | 掲載面、形式、期間、クリエイティブ案 |
| 4. 予算 | 内訳、媒体費、制作費、運用費 |
| 5. 効果測定 | 指標、測定方法、報告の頻度 |
| 6. スケジュール | 準備から掲載終了までの日程 |

## 2. 過去事例（架空）
### 事例: 地域鉄道会社（架空）の春の観光キャンペーン
- 期間: 2026年3月1日から4月30日（61日間）
- 目的: 沿線観光施設への来訪者を前年同期比で10%増やす
- 施策: 記事タイアップ4本、動画広告2本、地域版アプリのバナー掲載
- 予算: 総額1,200万円（媒体費900万円、制作費300万円）
- 結果: 特設ページの閲覧数は38万回、動画の完了視聴率は64%、来訪者数は前年同期比で8.5%の増加
- 反省点: 目標の10%には届かなかった。動画の公開が2週間遅れたことが一因と見ている

## 3. 起案時の留意点
- 目標値と実績の差は、隠さず原因とあわせて記載する。
- 記事タイアップには、広告であることを明示する表記を入れる。

## 4. 提出前の確認
- [ ] 目標値の根拠となる過去実績を添付した
- [ ] 媒体費と制作費の内訳が、見積書と一致している
- [ ] 提案書の提出期限を、広告主と合意した日程で確認した

## 5. 提案後の流れ
提案から1週間以内に、広告主へ進捗を確認する。受注した場合は、契約条件の確認に進み、制作の依頼書を編集・制作部へ回付する。
