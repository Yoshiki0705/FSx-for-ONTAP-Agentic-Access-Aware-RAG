# 広告出稿契約 標準条件書（2026年度）

対象部署: 広告営業部
改定日: 2026年4月1日

## 1. 適用範囲
本書は、当社媒体への広告出稿について、契約書の標準条件と、営業担当者が確認する事項を定める。

## 2. 標準条件
| 項目 | 標準 | 変更時の承認 |
|---|---|---|
| 支払サイト | 月末締め翌月末払い | 60日超は営業部長 |
| キャンセル料（掲載14日前まで） | 無料 | 不可 |
| キャンセル料（掲載13日前から7日前） | 掲載料の30% | 営業課長 |
| キャンセル料（掲載6日前以降） | 掲載料の100% | 営業部長 |
| 代理店手数料 | 15% | 20%超は役員承認 |
| 最低出稿金額 | 50万円 | 営業課長 |

## 3. 契約前チェックリスト
- [ ] 広告主の法人名と所在地を登記情報で確認した
- [ ] 広告表現が当社の広告掲載基準に適合している
- [ ] 競合排除の特約を求められていない、または承認を得ている
- [ ] 与信確認を行い、結果を記録した

## 4. 与信の目安
新規取引で月額300万円を超える場合は、与信審査を必須とする。審査の結果によっては、前払いまたは保証金を条件とする。

## 5. 契約書の保管
締結済みの契約書は、契約終了後5年間保管する。

## 6. 例外対応の記録
標準から外れる条件で契約する場合は、変更内容、承認者、承認日を契約管理表に記録する。2026年上期の例外承認は27件で、最も多かったのは支払サイトの延長（11件）であった。

## 7. 掲載後の請求
請求書は、掲載終了の翌月5営業日までに発行する。掲載実績が契約と異なる場合は、実績に基づいて請求額を調整し、広告主へ理由を説明する。
