# 記事・コンテンツ 校閲チェックリスト（2026年度）

対象部署: 編集・制作部
改定日: 2026年4月1日

## 1. 目的
公開前の記事、動画、画像について、事実確認と権利確認の漏れを防ぐための確認項目を定める。

## 2. 公開前の確認項目
### 事実関係
- [ ] 数字、日付、固有名詞を一次資料で確認した
- [ ] 取材対象の発言は、本人または広報担当者に確認を依頼した
- [ ] 統計の出典と調査時点を本文に明記した

### 権利・表現
- [ ] 写真、イラスト、音源の利用許諾を確認した
- [ ] 引用は、主従関係が明確で、出典を明記している
- [ ] 個人が特定できる情報は、本人の同意を得ている
- [ ] 差別的、または誤解を招く表現がない

## 3. 校閲の段階と所要日数
| 記事の種類 | 校閲者の人数 | 目安日数 |
|---|---|---|
| 速報記事 | 1名 | 当日中 |
| 通常記事 | 2名 | 2営業日 |
| 特集・連載 | 2名と編集長 | 5営業日 |

## 4. 訂正の対応
- 公開後に誤りを確認した場合は、2時間以内に編集長へ報告する。
- 訂正は、記事の冒頭または末尾に、訂正の日時と内容を明記する。
- 2026年上期の訂正は18件で、うち数値の誤りが11件であった。

## 5. 記録
校閲の記録は、公開から3年間保管する。記録には、校閲者、確認日時、指摘事項と修正の有無を残す。

## 6. 担当と連絡
校閲の担当は、毎週月曜日に編集長が割り当てる。判断に迷う表現は、編集長と法務担当へ連絡して確認すること。
