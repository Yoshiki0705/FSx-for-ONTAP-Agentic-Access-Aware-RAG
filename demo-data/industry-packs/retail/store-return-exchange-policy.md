# 返品・交換ポリシー（2026年度版）

## 概要
ミナモ・リテール株式会社（架空）の店舗およびECサイトにおける、お客様からの返品・交換の受付基準を定める。全店舗とECサポートで共通して適用する。

## 1. 受付期間と条件
| 区分 | 受付期間 | 条件 |
|------|----------|------|
| 店舗購入（未開封） | 購入日から14日以内 | レシートと商品が揃っていること |
| 店舗購入（開封済み） | 購入日から7日以内 | 初期不良に限る |
| EC購入（未開封） | 商品到着日から14日以内 | 返送送料はお客様負担 |
| EC購入（初期不良・誤配送） | 商品到着日から30日以内 | 返送送料は当社負担 |

## 2. 返品・交換できない商品
- 生鮮食品、およびお客様の希望で名入れ加工をした商品
- 下着類、衛生用品で開封済みのもの
- セール対象のうち「返品不可」と表示された商品

## 3. 返金方法
1. 現金払いは店舗窓口で現金返金する
2. クレジットカード払いはカード会社経由で取り消す。反映まで最大45日かかる場合がある
3. 1回の返金額が30,000円を超える場合は、店長の承認を得る

## 4. 窓口での確認チェックリスト
- [ ] 購入日と受付期間を確認した
- [ ] 商品の状態（未開封、開封済み、破損）を記録した
- [ ] 返金方法と金額をお客様に説明した
- [ ] 返品理由を所定のコード表に従って入力した

## 5. 改定履歴
- 2026年4月1日: EC初期不良の受付期間を14日から30日に延長

## 6. 苦情への対応
- 受付できない場合は、理由を丁寧に説明し、店長へ引き継ぐ
- 対応の内容は、当日中にお客様対応の記録へ入力する
