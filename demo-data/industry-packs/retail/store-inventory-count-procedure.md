# 店舗棚卸実施手順書

## 概要
店舗運営部が定める、半期ごとの棚卸の実施手順である。全店舗の店長と棚卸責任者が、この手順に従って実施する。

## 1. 実施スケジュール
| 回 | 実施日 | 営業時間 |
|----|--------|----------|
| 上期棚卸 | 2026年8月30日（日） | 21時で閉店し、22時から開始 |
| 下期棚卸 | 2027年2月28日（日） | 21時で閉店し、22時から開始 |

## 2. 体制
- 1店舗あたり、棚卸責任者1名、カウント担当4名、検品担当2名を置く
- カウント担当は、同一エリアを別の担当が再度確認する（ダブルカウント）

## 3. 手順
1. 開始前に、売場とバックヤードの在庫の移動を止める
2. ハンディ端末で、棚番号の順に商品をカウントする
3. 差異がシステム在庫の2%を超えるエリアは、再カウントする
4. 再カウント後も残る差異は、差異報告書に記録する
5. 翌営業日の正午までに、本部へ結果を送信する

## 4. 差異の判定基準
- 1店舗の在庫差異率が0.8%を超えた場合、原因調査を行う
- 単品で5万円を超える差異が出た場合は、店長が即日報告する

## 5. 確認チェックリスト
- [ ] 返品待ち、取り置き商品を別に仕分けた
- [ ] 値札のない商品を一覧にした
- [ ] カウント済みの棚に完了シールを貼った

## 6. 結果の報告
- 差異報告書には、商品名、差異数、推定原因を記入する
- 本部は、全店舗の差異率を集計し、2026年9月15日までに経営会議へ報告する
- 差異率が高い店舗には、翌期に抜き打ちの確認を行う
