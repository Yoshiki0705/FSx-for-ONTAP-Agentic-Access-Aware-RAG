# 2025年度 温室効果ガス排出量インベントリ（社内用）
## 目的
財団の事業活動に伴う温室効果ガス排出量を集計し、2026年度の削減計画の基準値とする。作成部署はサステナビリティ推進部である。
## 集計範囲
本部事務所、3か所の地域拠点、公用車12台、国内出張を対象とする。
## 排出量集計
| 区分 | 排出源 | 排出量（t-CO2e） |
|---|---|---|
| Scope1 | 公用車の燃料 | 18.4 |
| Scope2 | 購入電力（本部・拠点） | 96.7 |
| Scope3 | 国内出張（鉄道・航空） | 41.2 |
| Scope3 | 配布物の印刷・発送 | 22.5 |
| 合計 | | 178.8 |
## 算定上の注意
- 電力の排出係数は各電力会社の2025年度公表値を使用する
- 出張は移動距離と交通手段別の係数で算定する
- 拠点の電力量は検針票の値を用い、欠測月は前年同月で補完する
## 2026年度の削減計画
- 本部事務所の電力を再生可能エネルギー由来のプランへ切り替える（2026年7月予定、削減見込み 約40 t-CO2e）
- 公用車4台を電動車へ更新する（2026年度中）
- 目標は2025年度比5%減の169.9 t-CO2e以下とする
## 確認事項
外部公表前に、算定根拠の資料を保管したうえで推進部長の承認を得ること。
## 前年度との比較
2024年度の合計は185.3 t-CO2eであり、2025年度は3.5%減少した。主な要因は、本部事務所の照明をLEDに更新したこと（Scope2で約6 t-CO2e減）である。一方、出張は活動拡大により約3 t-CO2e増加した。
## 次回の見直し
算定方法は2026年12月に見直す。Scope3の対象カテゴリを、通勤と廃棄物へ広げるかを検討する。
