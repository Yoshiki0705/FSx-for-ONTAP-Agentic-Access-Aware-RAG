# ESG情報開示 事前確認チェックリスト
## 目的
サステナビリティ報告書や寄付者向け資料を公表する前に、記載内容を確認するための基準である。サステナビリティ推進部が運用する。
## 1. 数値の根拠
- [ ] 排出量、植樹本数などの数値に算定根拠の資料があるか
- [ ] 前年度との比較で増減が10%を超える項目に説明があるか
- [ ] 目標値と実績値の対象期間が揃っているか
## 2. 表現の確認
- [ ] 「カーボンニュートラル」「環境に優しい」など根拠の示しにくい表現を使っていないか
- [ ] 将来の見込みと実績を区別して書いているか
- [ ] 他団体の取り組みを自団体の成果として記載していないか
## 3. 範囲と境界
- [ ] 報告の対象範囲（拠点、期間）が冒頭に明記されているか
- [ ] Scope3の算定対象カテゴリが一覧で示されているか
- [ ] 算定対象外とした項目に理由があるか
## 4. 承認フロー
| 段階 | 担当 | 期限の目安 |
|---|---|---|
| 一次確認 | 推進部の担当者 | 公表の15営業日前 |
| 二次確認 | 推進部長 | 公表の10営業日前 |
| 最終承認 | 事務局長 | 公表の5営業日前 |
## 5. 公表後
- [ ] 公表した資料と算定根拠を7年間保管しているか
- [ ] 訂正が必要になった場合の連絡手順を確認したか
## 6. 差し戻しの基準
次のいずれかに該当する場合は、公表を延期して差し戻す。
- 数値の根拠資料が提出されていない
- 前年度の数値と定義が変わっているのに、説明がない
- 承認の記録が三段階とも揃っていない
差し戻した場合は、再提出の期限を担当者と推進部長で決め、記録に残す。
