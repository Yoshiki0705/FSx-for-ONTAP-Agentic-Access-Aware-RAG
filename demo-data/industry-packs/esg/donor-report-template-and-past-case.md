# 寄付者向け成果報告書 テンプレートと過去事例
## 用途
寄付者へ送る成果報告書を起案するための雛形と、過去事例である。サステナビリティ推進部と寄付・助成事業部が共同で使う。
## テンプレート
1. ご挨拶（寄付への謝意、報告対象期間）
2. 寄付金の使い道（金額と事業ごとの内訳）
3. 成果（数値と写真、現地の様子）
4. 今後の予定（次期の計画と時期）
5. 会計報告（収入、支出、残額）
6. 連絡先と寄付者情報の取扱いについての案内
## 過去事例: 里山再生プロジェクト報告（2025年度）
| 項目 | 内容 |
|---|---|
| 寄付総額 | 1,280万円（法人寄付3件、個人寄付412件） |
| 使途 | 苗木購入 520万円、下草刈りと管理 380万円、地域研修 210万円、事務費 170万円 |
| 成果 | 植樹 12,500本、活着率 87%（2026年2月調査） |
| 次期予定 | 2026年秋に追加植樹 8,000本 |
## 書き方の要点
- 寄付者ごとの金額は報告書に記載せず、総額で示す
- 活着率などの成果は、調査時期と方法を添える
- 実績が目標に届かなかった場合は、理由と対応策も書く
- 発送前に推進部と助成事業部の双方が確認する
## 発送スケジュールの目安
| 作業 | 期限 |
|---|---|
| 原稿の起案 | 発送の30日前 |
| 双方の確認 | 発送の14日前 |
| 印刷と宛名作成 | 発送の7日前 |
報告書は年2回、2026年6月と2026年12月に発送する。
## 確認のチェック項目
- 寄付総額と使途の合計が一致しているか
- 写真に写る人物の掲載許可を得ているか
- 次期予定の時期が事業計画と一致しているか
