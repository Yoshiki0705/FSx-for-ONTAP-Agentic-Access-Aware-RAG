# 助成金申請 審査基準（2026年度）
## 目的
寄付・助成事業部が、地域団体からの助成金申請を公平に審査するための基準を定める。審査は年2回、2026年5月と2026年11月に実施する。
## 助成の概要
- 1件あたりの上限額は300万円、助成期間は最長12か月
- 年間の助成総額は4,500万円を予定している
- 申請団体は設立から2年以上の非営利団体とする
## 審査項目と配点
| 項目 | 配点 | 確認内容 |
|---|---|---|
| 事業の目的と必要性 | 25点 | 地域課題が具体的な数字で示されているか |
| 実施体制 | 20点 | 担当者と協力団体の役割が明確か |
| 予算の妥当性 | 20点 | 見積書があり、管理費が総額の15%以内か |
| 成果指標 | 20点 | 測定方法と目標値があるか |
| 継続性 | 15点 | 助成終了後の運営計画があるか |
## 採択の目安
- 合計70点以上で採択候補とする
- 予算の妥当性が10点未満の場合は、他項目が高得点でも採択しない
## 審査上の留意点
- 理事や職員が関係する団体の申請は、当該者を審査から外す
- 申請書の内容に不明点がある場合は、書面で追加説明を求める
- 審査結果は申請から60日以内に通知する
## 提出書類
申請団体には次の書類を求める。
1. 申請書（所定様式、5ページ以内）
2. 直近2年分の決算書
3. 事業予算書と見積書の写し
4. 団体の定款または規約
書類に不足がある場合は、受付から10営業日以内に補完を依頼する。期限までに補完されない申請は、審査の対象としない。
