# 重要事項説明 事前チェックリスト
## 目的
賃貸管理部と売買仲介部が共通で使う、重要事項説明の前日までの確認項目である。2026年度版。社内の運用基準であり、法令への適合を保証するものではない。
## 物件の確認
- [ ] 登記事項の内容と契約書案が一致している
- [ ] 用途地域、建ぺい率、容積率を調査した
- [ ] 上下水道、ガス、電気の供給状況を確認した
- [ ] 過去の修繕履歴を管理会社から取得した
## 取引条件の確認
- [ ] 代金または賃料、支払時期を記載した
- [ ] 手付金の額が売買代金の10%以内である
- [ ] 解約と違約金の条件を記載した
- [ ] 契約不適合に関する責任の期間を記載した
## 説明の実施
| 項目 | 基準 |
|---|---|
| 説明の所要時間 | 40分以上を確保する |
| 事前の資料送付 | 説明の3営業日前まで |
| 説明者 | 取引士の資格を持つ者 |
| 記録 | 説明日時と同席者の役職を残す |
## 不備が見つかった場合
不備は説明の前日までに担当課長へ報告し、契約日を延期するか判断を受ける。2025年度は説明前の確認で、延べ47件の修正が発生した。
## 当日の進め方
1. 取引士が資格証を提示し、説明の対象と所要時間を伝える
2. 物件、取引条件、特約の順に、資料を示しながら説明する
3. 質問を受けた事項は、回答と根拠をその場で記録する
4. 説明を終えたら、相手方の理解の状況を確認し、署名を受ける
## 保管
説明に使った資料と記録は、契約の終了後5年間保管する。
## 担当者への連絡
確認項目の判断に迷う場合は、説明の2営業日前までに取引士の責任者へ相談する。当日の変更は原則として認めない。
