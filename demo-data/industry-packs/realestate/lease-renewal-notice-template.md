# 賃貸借契約 更新のお知らせ 文面テンプレート
## 使い方
賃貸管理部の担当者が、契約満了日の90日前から60日前までに借主へ送付する。【】の部分を物件ごとに置き換える。
## 文面
件名: 賃貸借契約の更新について（【物件名】【部屋番号】）

【借主名】様

いつもご利用いただきありがとうございます。ご契約の満了日が【満了日】に近づいておりますので、更新のご案内をいたします。

| 項目 | 内容 |
|---|---|
| 現在の賃料 | 【現行賃料】円 |
| 更新後の賃料 | 【更新後賃料】円 |
| 更新期間 | 2年間 |
| 更新料 | 賃料の1か月分 |
| 回答期限 | 満了日の45日前 |

更新を希望されない場合は、解約予告の書面を満了日の30日前までにご提出ください。
## 送付前チェック
- [ ] 賃料改定がある場合、オーナーの承認日を確認した
- [ ] 回答期限が満了日の45日前になっている
- [ ] 保証会社の更新手数料（1万円）を記載した
## 過去の改定事例
2025年度は更新対象312件のうち、賃料据え置きが271件、増額が31件、減額が10件であった。
## 送付後の対応
- 回答期限の10日前に、未回答の借主へ再度の案内を送る
- 更新しない旨の連絡を受けた場合は、退去立会いの日程を2週間以内に調整する
- 更新の手続きが完了したら、契約書の写しを借主とオーナーへ送付し、管理システムの契約期間を更新する
## 注意
更新料や賃料の扱いは契約書の特約が優先される。送付前に必ず契約書の原本を確認すること。
## 更新を希望しない場合の案内
解約予告の書面を受け取ったら、5営業日以内に受領の連絡を行い、退去日までの賃料の精算方法を案内する。
