# 設計変更申請書 テンプレート
対象: 車両開発部、品質保証部 共通 / 様式番号 DCR-2026
## 1. 申請の基本情報
| 項目 | 記入内容 |
|------|---------|
| 申請番号 | DCR-2026-(連番) |
| 申請日 | 2026年__月__日 |
| 対象車種・部品 | |
| 変更区分 | 性能向上 / コスト低減 / 不具合対策 / 法規対応 |
## 2. 変更内容
変更前と変更後の仕様を、図番と版数を付けて記載する。
## 3. 変更理由と影響範囲
- 変更の背景(市場不具合の件数、試験結果など)
- 影響する部品・工程・サプライヤ
- 既に生産した車両への対応(切替時期、在庫の処置)
## 4. 評価計画
- [ ] 必要な試験項目と実施時期
- [ ] 品質保証部による工程能力の確認
- [ ] 保安部品に該当する場合は、追加の審査会の開催
## 5. 承認フロー
| 変更区分 | 承認者 | 目安の期間 |
|---------|-------|----------|
| 軽微 | 課長 | 3営業日 |
| 一般 | 部長 | 10営業日 |
| 保安部品 | 品質担当役員 | 20営業日 |
## 6. 記入例
「充電ポートカバーの固定部品を、樹脂製から金属製に変更する。理由は、締結部の緩みの対策である。」
## 7. 提出時の注意
- 添付書類は、変更前後の図面、試験結果、コスト比較表の3点を基本とする。
- 申請から承認までの期間は、書類の不備があると延びる。提出前に課内で確認すること。
- 承認後の変更番号は、設計管理システムに登録し、関係部署へ通知する。
