# EVバッテリーパック 設計審査チェックリスト
管理部署: 車両開発部 電動パワートレイン課 / 第4版(2026年2月)
## 1. 目的
量産前の設計審査(DR2)で、バッテリーパックの設計が社内基準を満たしているかを確認する。
## 2. 審査項目
| 区分 | 基準値 | 確認方法 |
|------|-------|---------|
| セル温度差(急速充電時) | 5度以内 | 台上試験 |
| 冷却液流量 | 8L/分以上 | 流量試験 |
| パック質量 | 420kg以下 | 実測 |
| 絶縁抵抗 | 500Ω/V以上 | 絶縁抵抗計 |
| 防水(浸水試験) | 30分間の浸水後も異常なし | 水没試験 |
## 3. チェックリスト
- [ ] 熱暴走の伝播試験の結果を添付した
- [ ] 振動試験(合計40時間)で締結部の緩みがない
- [ ] 高電圧コネクタの誤接続防止を確認した
- [ ] 充放電サイクル1,000回後の容量維持率が80%以上である
## 4. 判定
全項目が合格で承認する。1項目でも不合格の場合は、是正計画を提出し、2週間以内に再審査を受ける。
## 5. 保管
審査記録は車両の生産終了後10年間保管する。
## 6. 過去の指摘事例
2025年度のDR2では、冷却液流量が7.4L/分で基準を下回り、不合格となった。流路の曲がりを減らす設計変更を行い、再審査で8.6L/分を確認して合格した。
## 7. 審査の参加者
審査には、設計担当、評価担当、品質保証部の代表者各1名以上が出席する。
## 8. 審査後の対応
指摘事項は審査当日に一覧化し、担当者と期限を決める。是正の完了は、次回の審査会までに車両開発部の課長が確認する。
