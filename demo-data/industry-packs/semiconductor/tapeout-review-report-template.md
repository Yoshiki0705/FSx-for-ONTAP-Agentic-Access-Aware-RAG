# テープアウト判定レビュー報告書（テンプレートと過去事例）

## 概要
設計部門がテープアウト判定会議に提出する報告書の標準様式。以下に、過去事例「ミックスシグナルSoC 型番 KS-2208」の記載例を示す。

## 1. 基本情報
| 項目 | 記載例 |
|---|---|
| 製品名 | KS-2208（車載向けセンサ制御SoC） |
| プロセス | HK7（架空の7nm相当） |
| 判定会議日 | 2026年5月21日 |
| 目標テープアウト日 | 2026年5月29日 |
| ダイサイズ | 38.4 mm2 |

## 2. サインオフ状況
| 検証項目 | 結果 | 備考 |
|---|---|---|
| DRC | 合格 | 致命的違反 0件、ウェーバー 12件 |
| LVS | 合格 | ミスマッチ 0件 |
| タイミング | 合格 | 最悪スラック +0.03 ns（全コーナー） |
| 消費電力 | 合格 | 動作時 1.8 W（上限 2.0 W） |
| ESD/IR ドロップ | 条件付き | IR ドロップ 4.8%（基準 5%）、改善策を実施済み |

## 3. 未解決課題と対応
- IP ブロックの第三者検証レポートが1件未着のため、5月26日までに受領する
- 低電圧モードのカバレッジが 93%（目標 95%）であり、追加テストを2件作成する

## 4. 判定提案
条件付きで承認を提案する。条件は、上記2件を5月26日までに完了することとする。

## 5. 起案時の注意
- 数値は最新の検証ログから転記し、転記日を記載する
- 条件付き判定には、期限と責任者の役割名を必ず記載する
- 前回判定からの差分を冒頭に3行以内で要約する
