# DRC/LVS サインオフ判定基準（社内設計部門限定）

## 概要
北嶺セミコンダクタ株式会社 設計部門が、7nm相当の架空プロセス「HK7」でテープアウト前に実施する物理検証のサインオフ基準。2026年3月改定。

## 1. DRC（デザインルールチェック）
| 区分 | 判定基準 |
|---|---|
| 致命的違反 | 0件であること。1件でもサインオフ不可 |
| 警告レベル違反 | 全体で50件以下かつ、各件に承認済みウェーバーがあること |
| ウェーバー申請 | 設計リード1名とプロセス連携担当1名の承認が必要 |

## 2. LVS（レイアウト対回路図検証）
- 不一致（ミスマッチ）は0件とする
- ショート、オープンはすべて解消する
- 電源ネットの接続確認は、全電源ドメイン（計6系統）で実施する

## 3. アンテナ・密度チェック
- メタル密度は各層で 20% から 80% の範囲内
- アンテナ比は、ゲート面積に対し規定値（HK7では400）以下
- 範囲外の場合は、ダミーフィル挿入後に再検証する

## 4. 判定チェックリスト
- [ ] 最新版のルールデックを使用している（2026年2月版以降）
- [ ] 検証ログに全ブロックが含まれている
- [ ] ウェーバー一覧が承認済みである
- [ ] ECO 後に DRC/LVS を再実行している
- [ ] 検証結果をレビュー会議資料に添付した

## 5. 再検証が必要な条件
IPブロックの差し替え、配線層の変更、ルールデックの更新があった場合は、全ブロックで再検証を行う。サインオフ判定は、テープアウト判定会議の5営業日前までに完了させる。
