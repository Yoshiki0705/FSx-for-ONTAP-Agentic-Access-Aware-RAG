# 作業停止(計画停止)調整ルール
対象: 送配電運用部、発電設備保全部 共通 / 2026年度版
## 1. 目的
発電所の定期点検と送電設備の作業停止が重なり、供給力が不足する事態を防ぐ。
## 2. 調整のスケジュール
| 時期 | 内容 |
|------|------|
| 前年度12月 | 年間停止計画の提出 |
| 3か月前 | 停止日程の確定会議 |
| 1か月前 | 変更申請の締切 |
| 前週火曜日 | 週間作業停止計画の最終確認 |
## 3. 調整基準
- 同一エリアで停止する発電機の合計は、同時に最大2台までとする。
- 夏季(7月1日〜9月15日)と冬季(12月20日〜2月10日)は、原則として計画停止を行わない。
- 停止により供給予備率が8%を下回る見込みの場合は、停止日の変更を求める。
## 4. 変更申請に必要な書類
- [ ] 作業停止申請書
- [ ] 供給力への影響試算(予備率の推移)
- [ ] 代替送電ルートの確認結果
## 5. 緊急停止の扱い
事故による緊急停止は、事後24時間以内に両部署へ報告する。
## 6. 事例
2026年3月に、第1発電所の3号機と第2発電所の1号機の停止日程が重なった。予備率の試算が7.4%となり基準の8%を下回ったため、第2発電所の停止を2週間後ろにずらした。
## 7. 連絡先の運用
調整会議の議事録は、会議の翌営業日までに両部署の課長へ共有する。
## 8. 例外の承認
基準から外れる停止を行う場合は、両部署の部長が書面で承認する。承認の記録は3年間保存し、翌年度の計画立案時に参照する。例外の件数は四半期ごとに集計し、年間で5件を超えた場合は基準の見直しを検討する。
