# 乗務員の労働時間管理の確認基準

## 概要
輸送管理部が、月次で乗務員の労働時間を確認するための社内基準である。運行計画を作成する前に、この基準を満たしているかを確認する。なお、法令への適合を保証するものではない。

## 1. 確認する項目と基準値
| 項目 | 基準値 | 超過時の対応 |
|------|--------|--------------|
| 1日の拘束時間 | 13時間以内（最大15時間） | 計画を修正する |
| 連続運転時間 | 4時間以内 | 30分以上の休憩を入れる |
| 休息期間 | 継続9時間以上 | 翌日の運行を変更する |
| 月間の拘束時間 | 284時間以内 | 部長へ報告する |

## 2. 運行計画の確認手順
1. 運行管理システムから、前月の勤務実績を出力する
2. 乗務員ごとに、上記4項目を照合する
3. 基準を超えた運行を、一覧表に記載する
4. 原因（待機、渋滞、積み込みの遅れ）を分類する
5. 翌月の計画に、改善策を反映する

## 3. 確認チェックリスト
- [ ] 全乗務員の勤務実績を取得した
- [ ] 基準を超えた運行を、一覧表に記載した
- [ ] 2か月連続で超過した乗務員を、面談の対象とした
- [ ] 点呼の記録が、運行ごとに残っている

## 4. 目標値
基準を超えた運行の割合を、2026年度末までに全運行の2%以下にする。2026年4月時点の実績は、5.8%である。

## 5. 記録の保管
- 勤務実績の一覧表は、3年間保管する
- 面談の記録は、輸送管理部の内部で保管し、他部署へ共有しない
