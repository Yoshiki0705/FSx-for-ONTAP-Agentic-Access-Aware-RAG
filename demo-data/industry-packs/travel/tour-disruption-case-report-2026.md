# 運休によるツアー中止の対応事例報告（2026年2月）
## 目的
運送機関の運休でツアーを中止した事例を整理し、今後の企画と顧客対応の際の参考にする。ツアー企画部とカスタマーサポート部が共同で使う。
## 事例の概要
| 項目 | 内容 |
|---|---|
| ツアー | 雪の北陸 温泉めぐり2日間（架空） |
| 出発日 | 2026年2月14日 |
| 参加予定 | 32名（16室） |
| 原因 | 大雪による幹線の終日運休 |
| 判断時刻 | 出発の前日17時 |
## 対応の経過
1. 前日17時に運休の見通しを確認し、中止を決定した
2. 前日18時までに全員へ電話で連絡し、メールでも案内した
3. 旅行代金は取消料なしで全額を返金した（総額 約98万円）
4. 宿泊施設へは、解除料を免除してもらうよう交渉した
## 結果
- 返金は受付から10営業日以内に完了した
- 宿泊施設の解除料は、契約上の発生額の半額に抑えられた
- 苦情は2件（連絡が遅いとの指摘）であった
## 今後の改善
- 運休の予報が出た時点で、前々日に参加者へ事前連絡する
- 代替日程のツアーを同時に案内できるよう、企画段階で候補日を用意する
## 代替ツアーの結果
2026年3月7日に同じ行程の代替ツアーを設定した。元の参加者32名のうち19名が参加し、新規の申込みは11名であった。参加率は59%で、代替日程を早く案内した方が、参加者の確保につながるという課題が残った。
## 関連する連絡手順
中止を決定した場合は、決定から1時間以内に全員へ連絡を始める。連絡がつかない参加者には、翌朝にもう一度電話をかける。
