# ツアー価格設定ガイドライン（2026年度）
## 目的
ツアー企画部が新規ツアーの価格を決める際の基準である。仕入原価と利益率の目安を統一する。
## 基本方針
- 旅行代金は、仕入原価に目標粗利率を加えて算出する
- 目標粗利率は、国内ツアーで18%、海外ツアーで14%とする
- 繁忙期は、通常期の代金に加算する
## 季節係数
| 時期 | 係数 |
|---|---|
| 通常期 | 1.00 |
| 春の大型連休（2026年4月29日から5月6日） | 1.35 |
| お盆（2026年8月8日から8月16日） | 1.40 |
| 年末年始（2026年12月28日から2027年1月4日） | 1.45 |
## 価格設定の手順
1. 宿泊、交通、食事、添乗員の原価を集計する
2. 最少催行人員（原則15名）で原価を人数割りする
3. 目標粗利率を加え、季節係数を掛ける
4. 100円未満を切り上げて設定する
## 承認
- 1人あたり20万円を超えるツアーは、企画部長の承認を得ること
- 粗利率が目標を3ポイント以上下回る場合は、事業部長の承認を得ること
## 割引の扱い
| 種類 | 割引率 | 条件 |
|---|---|---|
| 早期申込み | 5% | 出発の60日前までの申込み |
| 3名以上の同時申込み | 3% | 同一の予約番号 |
| 学生団体 | 8% | 20名以上 |
割引は重複して適用しない。最も割引率の高いものを1つだけ適用する。
## 見直しの時期
価格は四半期ごとに見直す。次回は2026年7月に実施し、原価の変動が5%を超えたツアーを優先して再計算する。
