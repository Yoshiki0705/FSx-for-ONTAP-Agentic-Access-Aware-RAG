# 新製品仕様書【極秘】

## プロジェクト名: Project HAYABUSA

**機密区分**: 極秘（社外秘・部門限定）  
**作成日**: 2024年10月1日  
**有効期限**: 製品発表日まで

## 製品概要

次世代高精度リニアアクチュエータ「HAYABUSA-X1」の製品仕様を定義する。本製品は従来品比で位置決め精度を10倍向上させ、半導体製造装置市場への参入を目指す。

## 主要仕様

| 項目 | 仕様値 | 従来品比 |
|------|--------|---------|
| 位置決め精度 | ±0.1μm | 10倍向上 |
| 最大推力 | 500N | 1.5倍向上 |
| 最大速度 | 2,000mm/s | 2倍向上 |
| 繰返し精度 | ±0.05μm | 5倍向上 |
| 動作温度範囲 | 15〜35℃ | 同等 |

## 技術的差別化要素

1. **独自開発リニアエンコーダ**: 分解能0.01μmの光学式エンコーダを内製化
2. **振動抑制制御**: AI予測モデルによるフィードフォワード制御を搭載
3. **熱変位補正**: リアルタイム温度計測による自動補正機能

- 2024年Q4: 試作1号機完成・基本性能評価
