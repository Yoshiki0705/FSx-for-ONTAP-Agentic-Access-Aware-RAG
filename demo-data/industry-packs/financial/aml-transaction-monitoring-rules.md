# 取引モニタリング ルール定義書（2026年度）

対象部署: コンプライアンス部
版数: 3.2（2026年5月1日施行）

## 1. 目的
口座取引の中から、不自然な動きを機械的に抽出し、調査対象とするためのシナリオと閾値を定める。

## 2. 検知シナリオ
| ID | シナリオ | 閾値 | 調査期限 |
|---|---|---|---|
| TM-01 | 現金の高額入出金 | 1日合計200万円以上 | 検知後5営業日 |
| TM-02 | 小口分割入金 | 7日間で50万円未満の入金が10回以上、合計300万円以上 | 検知後5営業日 |
| TM-03 | 休眠口座の突然の動き | 12か月以上無取引の口座で100万円以上の入出金 | 検知後3営業日 |
| TM-04 | 海外送金の急増 | 直近30日の送金額が過去6か月平均の3倍以上 | 検知後3営業日 |
| TM-05 | 高リスク国向け送金 | 金額を問わず全件 | 検知後2営業日 |

## 3. 調査の手順
1. システムが検知した案件を調査担当者に自動で割り当てる。
2. 取引目的、顧客属性、過去取引との整合性を確認する。
3. 疑わしいと判断した場合は、疑わしい取引の届出手順に引き継ぐ。
4. 疑わしくないと判断した場合は、理由を記録して終了する。

## 4. 閾値の見直し
閾値は半期ごとに、検知件数と届出件数の比率から見直す。2026年上期の検知件数は月平均412件、うち届出に至った割合は約2.4%であった。見直しの結果は、コンプライアンス委員会へ報告する。

## 5. 取扱注意
本書は検知条件を含むため、部外への開示を禁止する。
