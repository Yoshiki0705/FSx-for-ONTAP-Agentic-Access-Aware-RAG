# 疑わしい取引の届出手順

対象部署: 融資審査部、コンプライアンス部
改定日: 2026年3月15日

## 1. 適用範囲
融資の審査・実行・回収の過程、および預金取引のモニタリングにおいて、疑わしい取引を発見した場合の社内手順を定める。

## 2. 発見者の初動
- [ ] 取引の日時、金額、相手先、疑わしいと考えた理由を記録する
- [ ] 顧客に対し、疑いを持っていることを伝えない
- [ ] 当日中に所属部署の責任者へ報告する
- [ ] コンプライアンス部の受付窓口へ、所定の報告書を提出する

## 3. 判断と届出の流れ
| 段階 | 担当 | 期限 |
|---|---|---|
| 報告書の受付 | コンプライアンス部 | 受領後1営業日 |
| 事実確認と判断 | コンプライアンス部の担当者 | 受領後5営業日 |
| 届出の決裁 | コンプライアンス統括責任者 | 判断後2営業日 |
| 当局への届出 | コンプライアンス部 | 決裁後速やかに |

## 4. 融資審査部での留意点
- 資金使途と実際の資金の流れが一致しない場合は、報告の対象とする。
- 届出を行った顧客への新規融資は、コンプライアンス部の確認が済むまで保留する。

## 5. 記録の保管
報告書と判断の記録は、届出の有無にかかわらず7年間保管する。届出の事実は、顧客を含む社外へ開示してはならない。

## 6. 教育
対象部署の全員が、年1回の研修を受講する。2026年度の研修は、9月と2月の2回開催する。新規配属者は、配属後30日以内に受講すること。研修では、2025年度に社内で報告された事例を匿名化して取り上げ、初動の記録の書き方を演習する。
