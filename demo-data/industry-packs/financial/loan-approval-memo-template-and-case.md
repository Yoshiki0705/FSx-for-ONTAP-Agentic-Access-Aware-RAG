# 融資稟議書テンプレートと過去事例

## 1. 稟議書テンプレート
| 項目 | 記載内容 |
|---|---|
| 案件名 | 取引先名、資金使途、金額 |
| 申込内容 | 融資形態、金額、期間、返済方法、金利 |
| 業況 | 事業内容、売上推移、主要取引先 |
| 財務分析 | 直近3期の主要指標と審査基準との比較 |
| 保全 | 担保、保証、信用保証協会の利用有無 |
| 審査意見 | 承認、条件付承認、見送りのいずれかと理由 |

## 2. 過去事例（架空）
### 事例: 食品加工業 東雲フーズ株式会社（架空）
- 申込: 2026年2月、設備資金3,500万円、期間7年、元利均等返済
- 資金使途: 冷凍設備の更新。見積書は設備業者2社から取得済み
- 財務: 自己資本比率18%、インタレスト・カバレッジ・レシオ2.4倍、債務償還年数9.2年
- 課題: 自己資本比率が「要追加確認」の水準にあった
- 対応: 代表者の連帯保証と、設備への根抵当設定を条件とした
- 結果: 審査課長決裁（3,500万円のため）で条件付承認

## 3. 起案時の留意点
- 数値は決算書の期末日と出典を併記する。
- 審査基準との差異は、表の形で稟議書に明示する。
- 条件付承認の場合、条件の履行期限を日付で記載する。

## 4. 稟議書の添付資料
- 直近3期分の決算書と勘定科目内訳書
- 資金使途を裏付ける見積書、契約書の写し
- 担保物件の評価資料（担保がある場合）
- 取引先の信用調査報告書（与信額が3,000万円を超える場合）

## 5. 回付の流れ
起案者、審査課長、審査部長の順に回付する。決裁権限を超える案件は、融資審査会議の開催日の3営業日前までに事務局へ提出する。
