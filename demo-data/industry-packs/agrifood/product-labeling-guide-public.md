# ひなた野菜工房 商品表示ガイド（公開版）

## 概要
ひなた野菜工房株式会社（架空）が出荷する青果と加工品の、パッケージ表示の基本ルールを示す。2026年4月1日版である。

## 表示項目
| 項目 | 青果 | 加工品 |
|---|---|---|
| 名称 | 必須 | 必須 |
| 産地 | 必須（都道府県名） | 原料の産地を表示 |
| 内容量 | 必須 | 必須 |
| 賞味期限または消費期限 | 任意 | 必須 |
| 保存方法 | 推奨 | 必須 |
| 原材料名 | 不要 | 必須（使用量の多い順） |
| アレルギー表示 | 不要 | 必須 |

## 期限表示の目安
- カット野菜は消費期限とし、製造日を含めて4日間とする
- 冷凍の加工品は賞味期限とし、製造から180日間とする
- ジャムなどの瓶詰は賞味期限とし、製造から365日間とする

## 問い合わせ
表示に関する質問は、公式サイトの問い合わせフォームで受け付ける。回答までの目安は3営業日である。

## 産地表示の注意
- 複数の産地を混ぜた場合は、重量の多い順に表示する
- 加工品の原料原産地は、使用量が最も多い原料について表示する

## 表示の確認手順
1. 商品名と内容量を、出荷規格表と照合する。
2. 期限表示を、製造日から計算した日付と照合する。
3. アレルギー表示を、原材料の一覧と照合する。

## 表示を変更するとき
原材料や産地を変更した場合は、新しい表示のパッケージを使い始める前に、旧表示の在庫数を確認する。旧表示の在庫は、2026年内に使い切ることを目標とする。
