# 治験総括報告書 ドラフト様式と過去事例

## 概要
臨床開発部門が作成する治験総括報告書の標準構成と、過去事例（第2相試験 MZ-P2-014、架空）の記載例。起案時は、事例の書き方を参考に最新データへ置き換える。

## 1. 標準構成
1. 要約
2. 試験の目的と計画
3. 対象集団と症例の内訳
4. 有効性の結果
5. 安全性の結果
6. 考察と結論

## 2. 症例の内訳（記載例）
| 項目 | 例数 |
|---|---|
| 同意取得 | 168 |
| 登録（無作為化） | 120 |
| 試験完了 | 109 |
| 中止 | 11 |
| 解析対象（FAS） | 118 |

## 3. 有効性の記載例
主要評価項目である投与12週時の症状スコア変化量は、試験薬群 -8.4、プラセボ群 -3.1 であった（差 -5.3、95%信頼区間 -7.9 から -2.7）。

## 4. 安全性の記載例
有害事象は試験薬群の 61.7%（37/60）、プラセボ群の 55.0%（33/60）に認められた。重篤な有害事象は各群1例であった。

## 5. 起案時の注意
- 数値は統計解析報告書の確定版から転記し、版番号を明記する
- 因果関係の判断は、治験責任医師の評価を引用する
- 未確定の結果には、確定予定日（例：2026年8月31日）を付記する
- 本様式は社内用であり、特定の規制様式への適合を保証しない
