# プロトコル逸脱 対応手順書（臨床開発部門限定）

## 概要
瑞穂ファーマ株式会社 臨床開発部門が、治験実施中に発生したプロトコル逸脱を分類し、対応するための社内基準。2026年2月改定。

## 1. 逸脱の分類
| 区分 | 定義 | 例 |
|---|---|---|
| 重大 | 参加者の安全または主要評価項目の信頼性に影響する | 選択基準を満たさない参加者の登録 |
| 重要 | 副次評価項目やデータ品質に影響する | 来院時期が許容範囲（±3日）を超過 |
| 軽微 | 影響が限定的 | 記録の転記漏れ |

## 2. 対応期限
- 重大：認知後24時間以内に部門責任者へ報告し、5営業日以内に是正計画を作成する
- 重要：認知後3営業日以内に記録し、月次レビューで評価する
- 軽微：記録のうえ、四半期ごとに傾向を確認する

## 3. 判定チェックリスト
- [ ] 逸脱の発生日と認知日を区別して記録した
- [ ] 影響を受けた参加者数を特定した
- [ ] 解析対象集団から除外するか、事前に定めた基準で判断した
- [ ] 原因分析を実施した
- [ ] 同一施設で3か月内に同種の逸脱が2件以上ないか確認した

## 4. 施設への通知
同一施設で重要以上の逸脱が3件に達した場合は、モニタリング頻度を8週ごとから4週ごとに引き上げる。

## 5. 記録の保管
逸脱記録は試験終了後少なくとも15年間保管する（社内規程による。特定の法令への適合を示すものではない）。

## 6. 年次レビュー
臨床開発部門は、毎年1月に前年の逸脱件数を区分別に集計する。2025年は重大 4件、重要 31件、軽微 112件であった。集計結果は手順書の見直しに使う。
