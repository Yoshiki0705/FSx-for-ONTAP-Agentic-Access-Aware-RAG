# エンジニアリング プロダクトロードマップ 2026

## ビジョン

「AIファーストのデータプラットフォーム」を実現し、エンタープライズ顧客のデータ活用を根本的に変革する。

## Q1（1月〜3月）: 基盤強化フェーズ

### マイルストーン
- **Permission-aware RAG v2.0 GA リリース**（3月末）
  - マルチモーダル対応（PDF画像、図表の理解）
  - レスポンス時間50%改善（P95: 3秒→1.5秒）
  - 同時接続数10倍（100→1,000ユーザー）

- **ONTAP Connector v3.0**（2月末）
  - リアルタイムファイル変更検知（FSx CloudWatch Events連携）
  - 差分同期による KB 更新時間短縮（全件同期比 90%削減）
  - マルチボリューム対応

### 技術的課題
- Bedrock KB のメタデータフィルタリング性能限界（10万ドキュメント超）
- VPC内Lambda のコールドスタート対策（SnapStart検証）

## Q2（4月〜6月）: AI拡張フェーズ

- **マルチエージェント協調 v2**
  - 専門エージェント追加: コード生成、データ分析、レポート作成
  - エージェント間のコンテキスト共有最適化
  - 実行コスト30%削減（キャッシュ戦略）

- **音声インターフェース GA**
  - Pipecat Agent の本番品質化
  - 日本語音声認識精度 95%以上
  - リアルタイム翻訳対応（日英中韓）

## Q3（7月〜9月）: エンタープライズ機能

- **監査・コンプライアンス強化**
  - 全クエリの監査ログ（CloudTrail統合）
  - PII検出・マスキング自動化
  - SOC2 Type II 認証取得準備

- **マルチテナント対応**
  - テナント分離アーキテクチャ
  - テナント別コスト配分
  - SLA管理ダッシュボード

## Q4（10月〜12月）: スケール＆最適化

- **グローバル展開**
  - マルチリージョンデプロイ自動化
  - データレジデンシー対応（EU, APAC）
  - CDN最適化（レイテンシ200ms以下）
